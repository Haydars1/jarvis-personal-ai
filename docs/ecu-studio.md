# ECU Studio

JARVIS ECU Studio is a mobile-friendly browser workspace for generic ECU binary inspection.

Current capabilities:
- BIN/HEX/ORI/MOD local file loading
- Hex editing with undo/redo
- Offset jump and hex-pattern search
- Byte inspector (U8/U16/U32/S16/Float, LE/BE)
- ORI/MOD byte diff
- Generic candidate-region scan
- Per-file notes stored locally
- Modified binary export

The candidate scanner is heuristic and does not claim exact calibration/map identities.
